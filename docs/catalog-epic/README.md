# Эпик Catalog

Эпик Catalog объединяет просмотр коллекций NFT и действия с ними в приложении FakeNFT.

## Демонстрация

[Скринкаст эпика Catalog](./catalog-epic-demo.mov)

## Возможности

- Загрузка списка коллекций с сервера: обложка, название и количество NFT.
- Сортировка каталога по названию и по количеству NFT; выбранный вариант сохраняется.
- Открытие экрана коллекции с обложкой, названием, автором и описанием.
- Переход на сайт автора коллекции внутри приложения.
- Загрузка NFT коллекции по их id и отображение сеткой в три колонки: картинка, рейтинг, название и цена в ETH.
- Переход в готовую карточку NFT по нажатию на элемент сетки.
- Добавление NFT в избранное и удаление из него через сердце на картинке; красное сердце показывает, что NFT уже в избранном.
- Добавление NFT в корзину и удаление из неё через кнопку рядом с ценой; для NFT уже в заказе показывается иконка удаления.
- Состояния загрузки и ошибки с возможностью повторить запрос; при ошибке лайка или корзины коллекция остаётся на экране, а сообщение показывается в alert.

## Реализация

Экран каталога и экран коллекции построены на SwiftUI. Состояние и пользовательские действия вынесены во view model, сетевые операции коллекций — в `CollectionService`, избранного — в `FavoritesService`, заказа — в `CartService`. NFT загружаются через `NftService`. Карточка NFT открывается через уже существующий экран детали, новый экран для этого не делался. Результаты изменения избранного и корзины отображаются после успешного ответа сервера.

Для демонстрации используются данные коллекций и NFT, загружаемые приложением. Видео записано в симуляторе iPhone 18 Pro.
