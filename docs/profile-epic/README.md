# Эпик Profile

Эпик Profile объединяет просмотр и управление профилем пользователя в приложении FakeNFT.

## Демонстрация

[Скринкаст эпика Profile](./profile-epic-demo.mov)

## Возможности

- Загрузка профиля пользователя с сервера: фото, имя, описание, сайт, количество собственных и избранных NFT.
- Переход на сайт пользователя внутри приложения.
- Редактирование имени, описания, сайта и фото профиля. Фото можно изменить по URL или удалить.
- Проверка имени и URL сайта перед сохранением; отображение состояния загрузки, ошибок и возможности повторить запрос.
- Просмотр собственных NFT, включая сортировку по цене, рейтингу и названию.
- Просмотр избранных NFT и удаление NFT из избранного.
- Состояния загрузки, ошибки с повторным запросом и пустого списка; оформление поддерживает светлую и тёмную темы и крупный Dynamic Type.

## Реализация

Экран профиля и редактирование построены на SwiftUI. Состояние и пользовательские действия вынесены во view model, сетевые операции профиля — в `ProfileService`. Связанные экраны собственных и избранных NFT используют отдельные сервисы и view model. Результаты изменения профиля отображаются после успешного ответа сервера.

Для демонстрации используются данные профиля и коллекций, загружаемые приложением. Видео записано в симуляторе iPhone Air (iOS 26.5).
